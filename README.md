# sebastianmena.conmenas.com — portfolio

Portfolio personal de Sebastián Mena para reclutadores y trabajo remoto (frente F3 de
RUMBO). Inglés por defecto con selector ES (`lang/*.json`, aplicado por `habla.js`).

- HTML + CSS + JS planos, sin build. `motor.js` dibuja el fondo de estrellas
  (`<canvas id="stars">`), `scroll.js` maneja la navegación por secciones.
- Despliegue: extensión SFTP de VS Code con `.vscode/sftp.json` (`uploadOnSave`).
  El archivo real lleva la contraseña FTP y **no entra a git**; la plantilla es
  `.vscode/sftp.json.example`.
- Versión anterior (2018, tema galaxia, jQuery): `github.com/mensetian/mensetianweb`.
  No comparte código con esta.

**Los servicios para negocios de Ocaña NO van acá** — viven en `../sebamena`
(`sebamena.com`). Dos públicos, dos sitios.
